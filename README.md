Repo-Finder is a repository discovery application built using Java and Spring Boot. It fetches trending and top repositories from GitHub, helping developers explore popular open-source projects and discover repositories worth checking out.


## ✨ Features
- 🔥 Fetch trending GitHub repositories
- ⭐ Discover top repositories
- 🌐 Retrieve repository information using the GitHub API
- ⚙️ Backend powered by Spring Boot
- ☕ Built with Java
## 🛠️ Tech Stack
- Java — Backend programming language
- Spring Boot — Backend framework
- GitHub API — Repository data source
- Maven — Dependency management
## 🔄 How It Works
1. The application sends a request to GitHub.
2. GitHub returns repository data.
3. Spring Boot processes the response.
4. The application provides repository information to the client.
## 🚀 Getting Started
Prerequisites
- Java 17 or later
- Maven
- Git

## Clone the Repository
git clone https://github.com/Daksh-720/Repo-finder.git
cd Repo-finder
## Run the Application
- Using Maven:
mvn spring-boot:run
